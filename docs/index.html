Jelly_Titlerenamerr strips piracy website prefixes (5MovieRulz, TamilMV, TamilBlasters, etc.), rip tags, and tech specs. It leaves pristine movie titles and automatically extracts the release year directly into Jellyfin metadata.

Easy 1-Click Setup

Install via Jellyfin Plugin Repository

Add the repository manifest URL below directly into your Jellyfin Dashboard to receive automatic one-click installs and updates:

https://lalithchary.github.io/Jelly_Titlerenamerr/manifest.json
  1. Open Repositories
    In Jellyfin, navigate to Dashboard → Plugins → Repositories tab and click the + button.
  2. Paste Repository URL
    Set Repository Name to Jelly_Titlerenamerr and paste the manifest URL copied above. Click Save.
  3. Install from Catalog
    Go to the Catalog tab, find Jelly_Titlerenamerr, click Install, and restart your Jellyfin server.
Manual Install: Prefer manual installation? Download Jelly_Titlerenamerr.dll and place it in your Jellyfin plugins directory (%ProgramData%\Jellyfin\Server\plugins\Jelly_Titlerenamerr\ on Windows or /config/plugins/Jelly_Titlerenamerr/ on Linux/Docker), then restart Jellyfin.

Key Capabilities

Built specifically for real-world media collectors and home servers.

🌐
Complete Domain Stripper
Strips all changing piracy domains (.company, .cz, .lat, .to, .vip, .top) and leading prefixes like www.5MovieRulz.company - .
📅
Year in Metadata, Not Title
Keeps movie titles pristine (e.g. Lalithchary) while saving the release year (2026) into Jellyfin's dedicated ProductionYear metadata field.
📂
Library Selection GUI
Pick exactly which Jellyfin libraries to process. Enable on Movies while leaving other libraries untouched, or process everything.
⚡
Automatic Triggers
Runs automatically when new files are imported during library scans, when items are updated, or on-demand via Jellyfin Scheduled Tasks.
🧹
Audio & Technical Specs Removal
Cleans technical audio specifications ((DD+5.1 - 192kbps & AAC)), file sizes (2.1GB), quality resolutions, and scene tags.
✏️
Custom Keywords & Regex
Specify custom site names, release groups, or regular expressions directly from the GUI for instant personalization.
